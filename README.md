# cheers-fe

Frontend for the Cheers project — a React 19 single-page app built with Vite and TanStack Router.

> Status: initial scaffold. The routing, styling, and UI foundations are in place; feature routes have not been written yet.

## Tech stack

| Area | Choice |
| --- | --- |
| Build tool | [Vite 8](https://vite.dev) |
| UI | [React 19](https://react.dev) + TypeScript |
| Routing | [TanStack Router](https://tanstack.com/router) (file-based, auto code-splitting) |
| Styling | [Tailwind CSS v4](https://tailwindcss.com) via `@tailwindcss/vite` |
| Components | [shadcn](https://ui.shadcn.com) (`base-vega` style) on [Base UI](https://base-ui.com) |
| Icons | [lucide-react](https://lucide.dev) |
| Forms | [react-hook-form](https://react-hook-form.com) + [Zod](https://zod.dev) |
| State | [Zustand](https://zustand.docs.pmnd.rs) |
| Fonts | Inter (`@fontsource-variable/inter`) |
| Linting | ESLint 10 + typescript-eslint |

## Getting started

Requires [Bun](https://bun.sh) (the repo ships a `bun.lock`). Node + npm/pnpm also work if you prefer.

```bash
bun install
bun run dev
```

The dev server prints a local URL (default `http://localhost:5173`).

## Scripts

| Command | What it does |
| --- | --- |
| `bun run dev` | Start the Vite dev server with HMR |
| `bun run build` | Type-check (`tsc -b`) and build to `dist/` |
| `bun run preview` | Serve the production build locally |
| `bun run lint` | Run ESLint over the repo |

## Project structure

```
src/
  assets/            Static images imported by components
  components/ui/     shadcn primitives (button, field, input, label, separator)
  lib/utils.ts       Shared helpers (re-exports `cn`)
  routes/            File-based routes; __root.tsx is the app shell
  routeTree.gen.ts   Generated by @tanstack/router-plugin — do not edit by hand
  index.css          Tailwind entry, design tokens, light/dark theme variables
  main.tsx           App entry: creates the router and mounts React
public/              Served as-is (favicon.svg, icons.svg)
```

## Conventions

- **Path alias:** `@/` resolves to `src/` (configured in both `vite.config.ts` and `tsconfig.app.json`).
- **Routing:** add a file under `src/routes/` and the router plugin regenerates `routeTree.gen.ts` on save. The generated file is committed; don't edit it manually.
- **Adding components:** use the shadcn CLI, which reads `components.json` and drops files into `src/components/ui/`.

  ```bash
  bunx shadcn@latest add <component>
  ```

- **Theming:** colors and typography live as CSS custom properties in `src/index.css`. Dark mode is driven by the `.dark` class (`@custom-variant dark`).
